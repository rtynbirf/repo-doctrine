# ЛОГИКА ТРЕВОГИ · A-HUSH v2
### Поколение зубов №6–№11 · выведено из мировых практик 2026-11-19 · интегрировано в дом rtynbirf

*A-HUSH v1 («тишина стражей», зубы 1–5) учил, КОГДА молчать: грейс, тревога-однажды,
саморазоружение, очередь пушащих, ретрай записи. Третья волна ×332 и мировой опыт
(Git Docs, Google SRE, Datadog, incident.io, практики Dependabot 2026) показали
следующий слой: **кто вообще имеет право кричать**. Правило сигнатуры мира —
«сначала личность тревоги (dedup), потом родство (group), потом намерение (page only
on symptoms)» — из него выведены шесть зубов этого поколения. Ни одно правило ниже
не копирует источник: источники — проверка, зубы — наше.*

## Зуб №6 · ОДНА ОПТИКА (одна конфигурация CodeQL на репо)

| | |
|---|---|
| Симптом | CodeQL красный на ~30 репо синхронно: «CodeQL analyses from advanced configurations cannot be processed when the default setup is enabled». |
| Первопричина | Двойной страж: включённый default setup + наш advanced YAML смотрят в одну точку и бьют друг друга; SARIF advanced отклоняется сервером. |

## Эмерджентный принцип поколения: «ЛОГИКА ТРЕВОГИ»

1. **Личность.** Тревога имеет ключ и живёт в одном экземпляре (зубы №2+№7).
2. **Родство.** Повторные симптомы того же ключа не кричат — дописываются в существующую историю (зубы №2, №8).
3. **Намерение.** Кричит только то, что не может излечиться само; всё самоисцеляющееся проходит через грейс ≥ цикл лечения (зуб №11).
4. **Одна оптика.** На одну территорию смотрит один страж, а не два (зуб №6); территория = дефолтная ветка, транзит вне стража (зуб №9).
5. **Такт вместо склада.** Обновления и тревоги идут по такту конвейером; любое накопление (очередь PR, башня уведомлений) = симптом сломанного такта (зуб №10, Г-4).
