## Ось 9 · Внешний судья

**Мир.** Движки измеряют себя Web Platform Tests (Servo, Ladybird, Verso:
счёт passing — единственная общая шкала); библиотеки — бенчмарками против
мейнстрима (LangGraph/CrewAI для мультиагентности); зрелость репо — внешними
шкалами (OpenSSF Scorecard, который дом уже крутит в singulyar ритуалом,
6/6 зелёных).

**Факт дома (проверено API 2026-11-18).** В 260 файлах workflows живой части
флота все 30 уникальных внешних `uses:` пиннуты на полные SHA — внутренняя
дисциплина есть. Но: README neutral-browser (42 КБ) не упоминает WPT ни разу;
в polymath-multiagent 10 тестовых файлов (`tests/test_*.py`) доказывают
работоспособность, не превосходство; инструкция запуска в README есть.

**Эмерджентный принцип дома: «Работает ≠ доказал превосходство; нужен внешний счётчик».**
Внутренние вердикты (19/19 PASS, SELF_TEST=PASS, VERDICT) — суд дома над
собой. Снаружи принимается только счётчик, который дом не контролирует:
чужая шкала, чужой набор тестов, чужая система рядом. Отказ от внешнего
счётчика — не скромность, а замкнутый контур: вердикт ссылается на сам себя.

Ограничения платформы: `allowed_actions=selected` и `sha_pinning_required` через
API личных аккаунтов недоступны (404) — галка SHA ставится в UI, разрыв нулевой.

## Что из разбора НЕ принято (и почему)

Нейминг («рой», «кровь», «геном») и плотность мифологии витрины — разбор сам
помечает это осознанным tradeoff адресата, а не дефектом. Стиль дома — выбор
Хозяина; волна его не меняет. Единственное, что дом берёт из разбора целиком:
**два структурных провала — внешний счётчик и внешние пользователи.** Первое —
этот файл и два issue; второе — следствие первого (числа, которые можно
цитировать, и есть приглашение).
