# 01 · ЧЕК-ЛИСТ НАСТРОЕК РЕПОЗИТОРИЯ

Всё, что нажимается в `Settings` репозитория, — с пояснением «зачем» и
рекомендованным значением для наших репо. Путь в UI: репо → `Settings` → `General`.
Внизу — те же действия через API (без браузера, для агентов).

---

## 1. About (верх страницы репо)

| Флаг/поле | Что это | Рекомендация |
|---|---|---|
| Repository name | Имя | Латиницей, дефисы; осмысленно, а не `repo2` |
| Description | Описание в шапке и поиске | Одной фразой: что это, для кого, чем отличается. Никаких «test», «draft» |
| Website | Ссылка рядом с описанием | URL GitHub Pages, если есть; иначе пусто |
| Topics | Метки поиска | 5–15 штук, lowercase, через дефис. `About` → шестерёнка. Это SEO репозитория |
| Social preview | Картинка-превью | **Только через UI** (API нет): Settings → General → Social preview → Upload. 1280×640 |

## 2. Features

| Флаг | Что это | Рекомендация |
|---|---|---|
| Issues | Задачи и баги | **ВКЛ** — это тикетница проекта |
| Wiki | Отдельная вики | **ВЫКЛ**, если не используется: мёртвый груз и лишняя поверхность. Доки — файлами в репо |
| Projects | Канбаны | **ВЫКЛ**, пока не ведёте канбан |
| Discussions | Форум | **ВЫКЛ**, пока нет сообщества |

## 3. Pull Requests (как сливать ветки)

| Флаг | Что это | Рекомендация |
|---|---|---|
| Allow merge commits | Обычный merge-коммит | **ВКЛ** |
| Allow squash merging | PR сжимается в один коммит | **ВКЛ** — история читаемая |
| Allow rebase merging | Перезапись коммитов без merge | **ВЫКЛ** — ломает связность истории |
| Automatically delete head branches | Ветка удаляется после merge | **ВКЛ** — гигиена |
| Allow auto-merge | PR сам сольётся, когда зелёный | **ВКЛ** |
| Update branch automatically | Ветка сама подтягивает main | **ВКЛ** |
| Use PR title for squash commits | Заголовок коммита = заголовок PR | **ВКЛ** |
| Suggest updating pull request branches | Подсказки устаревших веток | ВКЛ |

## 4. Danger Zone

| Действие | Правило |
|---|---|
| Change visibility | Только по решению Хозяина; перед этим проверить, что в репо нет секретов |
| Archive | Для мёртвых проектов; архив = read-only, ничего не ломается |
| Delete | **Только вручную и только Хозяином.** Удалённое можно восстановить 90 дней (см. `05-аварийные-процедуры.md`) |

## 5. Security (репо → Settings → Advanced Security / Code security)

| Флаг | Что это | Статус 2026-11-01 |
|---|---|---|
| Secret scanning | Ищет утечки токенов в коде | **Публичные: ВКЛ** (бесплатно). Приватные: нужен Advanced Security |
| Push protection | Блокирует push, если в коде секрет | **Публичные: ВКЛ**. Это страховка от «случайно закоммитил токен» |
| Dependabot alerts | Предупреждает об уязвимых зависимостях | **ВКЛ всем** (бесплатно) |
| Automated security fixes | Dependabot сам присылает PR с фиксом | **ВКЛ всем** |

## 6. GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → `main` → `/ (root)` или `/docs`.
Сайт появится на `https://rtynbirf.github.io/<репо>/`. После включения пропиши
URL в поле Website (раздел About).

## API: то же самое без браузера

```bash
# токен НИКОГДА не пишется в команду из файла истории — только переменная окружения
export GH_TOKEN=$(cat ~/.gh-token)      # см. 03-токены-и-секреты.md
H="Authorization: Bearer $GH_TOKEN"
B="Accept: application/vnd.github+json"

# флаги + описание
curl -XPATCH -H "$H" -H "$B" https://api.github.com/repos/OWNER/REPO \
  -d '{"description":"...", "has_wiki":false, "has_projects":false,
       "delete_branch_on_merge":true, "allow_rebase_merge":false,
       "allow_auto_merge":true, "use_squash_pr_title_as_default":true}'

# topics
curl -XPUT -H "$H" -H "$B" https://api.github.com/repos/OWNER/REPO/topics \
  -d '{"names":["anticensorship","tor","pac"]}'

# Dependabot
curl -XPUT -H "$H" https://api.github.com/repos/OWNER/REPO/vulnerability-alerts
curl -XPUT -H "$H" https://api.github.com/repos/OWNER/REPO/automated-security-fixes
```

Проверка результата: `curl -H "$H" https://api.github.com/repos/OWNER/REPO | jq '.has_wiki, .delete_branch_on_merge'`

## Проверка «репо настроено по-человечески» (30 секунд)

- [ ] Описание понятно постороннему
- [ ] Topics 5–15
- [ ] Wiki/Projects выключены (или реально используются)
- [ ] Squash по умолчанию, rebase выключен, ветки чистятся сами
- [ ] main защищён от force-push (публичное) 
- [ ] Secret scanning + push protection (публичное)
- [ ] Dependabot-алерты и автофиксы включены
- [ ] Репо внесено в карту `06-карта-аккаунта.md`
