# 25 · РИТУАЛ ДОМА · Конечный автомат агента (закон №13)

**Статус:** канон дома · **Дата:** 2026-11-10 · **Введён:** Хозяин-обходом флота (51 репо) · **Приёмка:** исполняющий автомат `polimat-hub → tools/ritual_sweep.py` + workflow `ritual-sweep.yml`, зелёный прогон = акт ввода в силу.
**Мандат Хозяина:** «поработал? сделал? убрал за собой — никаких нотификаций и issues быть не должно; всё закрывать и решать самостоятельно; всё автоматическое — человек не делает того, что может автомат».

---

## 1. Формула дома

**ПОРАБОТАЛ → СДЕЛАЛ → УБРАЛ ЗА СОБОЙ → ДОМ ЧИСТ.**

Ритуал — не список пожеланий, а **детерминированный конечный автомат Мура**: выход (след в мире) определяется только состоянием, переходы — только событиями-фактами. Автомат останавливается в единственном допустимом финальном состоянии — **ЧИСТ**. Остановка в грязном состоянии ЗАПРЕЩЕНА (инвариант остановки).

## 2. Состояния (Q)

| # | Состояние | Смысл | Выход (след) |
|---|---|---|---|
| S0 | ВХОД | мандат получен | пусто (ничего не тронуто) |
| S1 | РАЗВЕДКА | карта до действий: API/клоны/тренды, UNKNOWN ≠ FALSE | снимок факта (JSON/файл), 0 мутаций |
| S2 | РАБОТА | атомарные мутации: коммиты, посадки, диспатчи | коммиты с факт-сообщениями |
| S3 | ПРИЁМКА | живые байты: HEAD до/после, зелёные прогоны, API-сверки | вердикт построчно |
| S4 | УБОРКА | снятие СВОИХ следов (см. §4) | 0 неснятых следов |
| S5 | ЧИСТ | финал | строка в PULSE, 0 unread своих, 0 исполненных-не-закрытых |

## 3. Переходы (δ)

| Из | Событие | В |
|---|---|---|
| S0 | мандат | S1 |
| S1 | карта собрана | S2 |
| S1 | UNKNOWN (не знаешь — не выдумывай) | S1 (добор факта) |
| S2 | атом исполнен | S3 |
| S3 | зелёный прогон / HEAD сошёлся | S4 |
| S3 | красный / расхождение | S2 (чинить) или честная пломба-блокер → S4 |
| S4 | предикат чистоты P = истина | **S5 (halt)** |
| S4 | P = ложь (есть след) | S2 (убрать след — это тоже работа) |

Правила автомата:
1. **Переход без события-факта запрещён** («по настроению» — нет такого события).
2. **Внешний блокер** (квота, WAF, чужая квота, слово Хозяина) переводит не в грязь, а в **честную пломбу** (issue/комментарий с внешней причиной) → S4.
3. **Решение Хозяина** — легитимное событие, но не место парковки автоматической работы: всё, что может сделать агент, делает агент (закон дома).
4. Очередь работы (не исполнено, но запланировано с приёмкой) — **не грязь**; исполненное-но-не-закрытое — **грязь**.

## 4. Предикат чистоты P (машинный, все пункты обязательны)

- **П1 · Нотификации:** unread-следов от своих действий = 0 (своё подметается сразу; наследные чужие не трогаются — У-5).
- **П2 · Issues:** не существует issue, чья приёмка исполнена и издана, но который открыт. Отчёты волн («ОТЧЁТ О ПРОДЕЛАННОМ») закрываются сразу после издания — отчёт не доска объявлений, а след.
- **П3 · CI:** у каждого workflow последнего прогона либо 🟢, либо честная пломба внешней причины. Красное без пломбы = грязь.
- **П4 · Посадки:** каждая посадка = СТОП-ГОРН (HEAD до/после) + приёмка мимо CDN (Contents API, У-4) + SHA-пины workflow (У-7).
- **П5 · Документы:** отчёт волны издан файлом в репо (чат умирает — файл живёт; append-only).
- **П6 · Числа:** ни одного ручного числа; счётчики — из живого API между маркерами (У-7).

## 5. Исполняющий автомат (реализация)

- **Канон:** этот файл (repo-doctrine, номер 25).
- **Исполнитель:** `polimat-hub → tools/ritual_sweep.py` — stdlib, только API, квота-лёгкий: (1) невод фактов (нотификации, открытые issues флота, последние прогоны активных клеток); (2) уборка: авто-закрытие отчётов волн старше 6 ч и чистых вердиктов дозора с фактическим комментарием; подметание своих ci_activity-нотификаций; (3) пломба: строка вердикта в `PULSE.md` между маркерами `<!-- RITUAL:BEGIN -->` / `<!-- RITUAL:END -->` (обновляет только своё, чужое не трогает).
- **Ритм:** workflow `ritual-sweep.yml` в polimat-hub — крон «37 2 * * *» (свободное окно, урок У-5) + ручная дверь `workflow_dispatch`; concurrency-группа против гонок самого себя.
- **Прозрачность:** каждый прогон оставляет в логе JSON-свод и строку в PULSE. Тишина автомата = дом чист.

## 6. Сверка с миром (что взято, что своего)

Взято у мира: машинные контроли вместо обещаний (OSPS Baseline, OpenSSF Scorecard), гигиена воркфлоу (zizmor), метрики потока (DORA), SLA-репорт инцидентов (EU CRA 24 ч), immutable-релизы (_supply-chain 2026_), инвариант «документ как релиз» (semver+CHANGELOG). Своё — **эмерджентное**: ритуал как формальный автомат с машинным предикатом остановки. Мир пишет чек-листы, которые люди забывают; дом исполняет автомат, который не умеет забыть. Человек в контуре только там, где закон оставляет слово Хозяину (деньги, публикация, необратимое).

## 7. Границы (чего ритуал НЕ делает)

Не трогает наследные чужие следы (У-5), не закрывает трекеры/очереди/решения Хозяина (§3.4), не переписывает историю (append-only), не дублирует чужие живые волны (§3 реестра), не сажает числа руками (У-7). При конфликте с параллельной волной сиблинга — уступает и перепроверяет (урок Я-13: PUT поверх чужого — только после diff).
