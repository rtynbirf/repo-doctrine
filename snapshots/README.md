# snapshots/ — машиночитаемые снапшоты карты аккаунта (П-03)

Это JSON-слой пары «доктрина = код»: prose-версия дельты живёт в `06-карта-аккаунта.md`
(для Хозяина), а здесь лежит снапшот `2026-11-08.json` (для роя) — все репо эпохи
2026-11-08T21:26:00Z со статусами `живая`/`поглощена` (+`absorbed_into`)/`архив`/`новая`,
кластером и хеш-пломбой в `MANIFEST_SHA256.txt`. Обновлять так: снять живой API
(`GET /user/repos`), записать новый файл `snapshots/<дата>.json` тем же коммитом с
пересобранным манифестом (`make manifest`) — гейт T17 красный, если пломба отстала от тела.
Закон снимков: **старый снапшот не удалять и не переписывать** — история территории читается
только добавлением; любой агент обязан уметь приложить `diff(снапшот, живой API)` —
если расхождение не объясняется полями `absorbed_into`/`новая`, карта отстала и её надо
внести по правилу 1 карты. Поглощения не выдумываются: статус `поглощена` ставится только
по документированному факту (см. `notes` внутри JSON).
