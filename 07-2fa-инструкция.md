# 07 · 2FA ЗА 7 ШАГОВ (единственная дверь, открытая только Хозяину)

**Почему это не сделал агент (и не сделает ни один):** у GitHub API нет
команды включения 2FA — принципиально. Если бы токен мог управлять вторым
фактором, кража токена означала бы полный захват аккаунта с отключением
защиты. GitHub сознательно оставляет это владельцу пароля. Это замысел:
второй фактор и должен быть вторым фактором.

**ТЕЛЕФОН НЕ НУЖЕН.** Требование GitHub — второй фактор, а не телефон.
TOTP-ключ — это текстовая строка; шесть цифр из неё умеет считать любой
десктоп-клиент на рабочем боксе. QR — лишь один из двух способов передать
ключ; второй — кнопка `enter this text code instead` прямо под QR.
(Правка 2026-11-01: первая редакция упиралась в мобильные приложения —
Хозяин указал на ошибку дислокации. Исправлено.)

**Когда:** сегодня, 15 минут. Что нужно: бокс 6ORMAN (Win11) и браузер.

## Путь A (основной): KeePassXC — TOTP прямо на боксе

Менеджер паролей + генератор TOTP в одной офлайн-базе. Без аккаунта,
без телефона, без облака. Все ключи и пароли — в одном сейфе.

1. **Установить.** `keepassxc.org` → Download → Windows Installer →
   установить → создать базу → мастер-пароль записать НА БУМАГУ
   (база без пароля мертва; пароль без базы тоже).
2. **GitHub, браузер:** аватар → `Settings` → `Password and authentication`
   → блок Two-factor authentication → `Enable two-factor authentication`
   → ввести пароль аккаунта.
3. **Выбрать `Authenticator app`** → `Continue` → на экране с QR нажать
   ссылку **`enter this text code instead`** → появится строка-ключ →
   скопировать её.
4. **KeePassXC:** создать запись `GitHub (rtynbirf)` → правой кнопкой
   по записи → `TOTP` → `Setup TOTP...` → вставить ключ в поле Secret →
   `OK`. Код появляется прямо в записи (обновляется каждые 30 сек).
5. **Копнуть код в GitHub:** `TOTP` → `Copy` → вставить 6 цифр →
   `Continue`. Всё — 2FA включена.
6. **КОДЫ ВОССТАНОВЛЕНИЯ — ОБЯЗАТЕЛЬНО.** GitHub покажет 10 одноразовых
   кодов → `Download` → файл `github-recovery-codes-*.txt` положить
   вложением в базу KeePassXC И копией на флешку. ДВА МЕСТА. НЕ в репо,
   НЕ в чат. Это единственный вход, если база/бокс умрут.
7. **Проверка.** Приватное окно браузера → вход в GitHub → должен
   спросить код из KeePassXC. Спросил — щит поднят.

## Путь B (минимализм): WinAuth

`github.com/winauth/winauth` — крошечное Windows-приложение, только TOTP.
Установить → Add → Authenticator → вставить тот же setup key → код на
экране. Минус: хранит всё в одном файле без мастер-пароля — копию файла
держать на флешке.

## Путь C (если захочется синхронизации): Ente Auth

`ente.io/auth` — открытый код, десктоп-версии Windows/Linux/macOS,
работает офлайн, облачная синхронизация опциональна и сквозно шифрована.

## Бонус после включения: пасскей Windows Hello (вход вообще без цифр)

`Settings` → `Password and authentication` → `Passkeys` → `Add a passkey`
→ Windows Hello (PIN бокса). Дальше GitHub будет просить PIN бокса, а не
6 цифр. Нюанс: пасскей живёт в профиле Windows этого бокса. Бокс умер —
вход по кодам восстановления, затем перевыпуск пасскея. Поэтому коды —
святое, см. шаг 6.

## После включения

- **Агентский пайплайн не ломается:** git-пуши работают по токенам (PAT),
  2FA на них не влияет. Отвалится только вход в браузер без второго
  фактора — то, ради чего всё.
- Браузерные сессии, где уже вошли, продолжат работать; следующий вход
  попросит второй фактор.
- Ежемесячная проверка (по `03-токены-и-секреты.md`): коды на месте,
  пасскей/ключи узнаваемы, чужих входов в Security log нет.
- Отметить в ворклоге: `TH-GH-02` → строка «2FA включена».

## Аудит агента по API (2026-11-01, TH-GH-02)

Всё, что токен берёт, агент проверил сам: 20 репо — deploy keys: 0,
прямые соавторы: только владелец, вебхуки: 0, Actions-секреты: 0.
Аномалий нет. Поле `two_factor_authentication` fine-grained токен не
отдаёт (особенность нового типа токенов) — истина в браузере:
`Settings → Password and authentication`: если 2FA выключена, там висит
жёлтая плашка Enable two-factor authentication с пометкой critical.
SSH/GPG-ключи профиля и Authorized OAuth Apps API не отдаёт — глянуть
руками: там должно быть пусто.
