# 07 · 2FA ЗА 7 ШАГОВ (единственная дверь, открытая только Хозяину)

**Почему это не сделал агент (и не сделает ни один):** у GitHub API нет
команды включения 2FA — принципиально. Если бы токен мог управлять вторым
фактором, кража токена означала бы полный захват аккаунта с отключением
защиты. GitHub сознательно оставляет это человеку с вторым фактором в руках.
Это не недоработка, а замысел: второй фактор и должен быть вторым фактором.

**Когда:** сегодня, 15 минут. Что нужно: телефон с любым TOTP-приложением
(Microsoft Authenticator, Google Authenticator, Aegis, 2FAS — любое).

---

## Шаги

1. **Подготовь приложение.** Поставь на телефон TOTP-приложение из списка выше.
   Никаких аккаунтов заводить не надо — только «добавить ключ».

2. **Войди в GitHub на ПК** браузером → правый верхний аватар → `Settings`.

3. **`Password and authentication`** → блок **Two-factor authentication** →
   кнопка **`Enable two-factor authentication`** → введи пароль аккаунта.

4. **Выбери `Authenticator app`** → `Show QR code` / `Set up using an app`.
   На телефоне: в приложении «+» → «Сканировать QR-код» → наведи на экран.
   (Если телефон в другом месте — жми `setup key` и введи код вручную.)

5. **Введите 6-значный код** из приложения (он обновляется каждые 30 секунд —
   успей до смены) → `Continue` → `Save`.

6. **КОДЫ ВОССТАНОВЛЕНИЯ — ОБЯЗАТЕЛЬНО.** GitHub покажет 10 одноразовых кодов.
   Нажми `Download` И ещё лучше — распечатай/перепиши на бумагу. Спрячь не в
   облаке с открытым доступом (бумага, флешка, сейф). Это единственный вход
   в аккаунт, если телефон утонет/сгорит/потеряется. Без них — только
   поддержка GitHub и недели ожидания.

7. **Проверка.** Открой приватное окно браузера, войди в GitHub заново:
   должен спросить код из приложения. Спросил — щит поднят.

---

## После включения

- **Ничего в агентском пайплайне не сломается:** git-пуши агентов работают
  по токенам, а не по паролю — 2FA на них не влияет.
- Браузерные сессии, где уже вошли, продолжат работать; следующий вход
  попросит код.
- Опционально (усиление): в том же разделе можно добавить SMS-резерв
  или физический ключ (FIDO2), и запретить вход без 2FA-кода вовсе.
- Отметить выполнение в ворклоге: `TH-GH-02` / строка «2FA включена».
